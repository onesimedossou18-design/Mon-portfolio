# Portfolio DOSSOU Onésime

Ce projet est un portfolio personnel en HTML, CSS et Bootstrap.

## Hébergement sur GitHub Pages

1. Créez un dépôt GitHub.
2. Placez ce dossier dans le dépôt.
3. Poussez les fichiers vers la branche `main`.
4. Dans GitHub, activez GitHub Pages dans les paramètres du dépôt.
5. Choisissez la branche `main` et le dossier `/(root)`.

Le site sera disponible à l'adresse suivante :
`https://<votre-nom-utilisateur>.github.io/<nom-du-depot>/`
